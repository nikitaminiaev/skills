# Очистка кэша opencode

## Проблема

opencode кэширует список скилов при первом запуске. Если скилы добавлены/удалены после старта, старый кэш продолжает использоваться. Симптомы:

- Из одной директории видны не все скилы
- Новые скилы не появляются
- Странности в поведении между разными директориями

## Решение

```bash
rm -rf ~/.local/share/opencode/repos/* ~/.local/share/opencode/snapshot/*
```

После очистки перезапустите opencode.

## Когда использовать

- Скилы не загружаются из текущей директории
- Добавили новый скилл, но он не появился
- opencode ведёт себя по-разному из разных директорий
