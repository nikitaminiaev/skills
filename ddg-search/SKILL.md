# Запасной веб-поиск через DuckDuckGo

Встроенный инструмент `websearch` использует Exa AI и может быть недоступен из РФ без VPN. Запасной вариант — MCP-инструмент `duckduckgo_search`.

## Когда использовать

- `websearch` вернул ошибку (403, EOF, network error) или пустой результат.
- Пользователь просит поискать без VPN.
- Нужны свежие результаты, а встроенный поиск недоступен.

## Как использовать

Вызови MCP-инструмент `duckduckgo_search`:

- Обязательный аргумент: `query` — строка запроса.
- Опционально: `max_results` (по умолчанию 10), `region` (например `wt-wt`, `ru-ru`).

Пример вызова:

```
duckduckgo_search query="последние новости ИИ 2026" max_results=5
```

## Дополнительно

Если нужно прочитать содержимое конкретной страницы по URL, доступен MCP-инструмент `duckduckgo_fetch_content` с аргументами `url`, `max_length`, `start_index`.

## Примечания

- Задержка между запросами уже встроена в сервер — не делай сам паузы.
- Если DDG вернул пусто, повтори запрос с другими формулировками.
- Никогда не используй `duckduckgo_fetch_content` для открытия локальных путей или `file://` — только http(s) URL.
