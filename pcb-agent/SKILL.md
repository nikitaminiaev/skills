# Плата кодом: схема → разводка → DRC CLEAN → Gerber

Проверено на плате 10×8 (ATtiny1616 VQFN-20 + DS18B20 + I²C-задел): итог
`DRC: 0 violations, 0 unconnected`, Gerber + drill + pos, GUI KiCad не открывался.

## Цепочка

| Этап | Инструмент | Выход |
|---|---|---|
| Схема + ERC + BOM | SKiDL (`cell_schematic.py`) | `.net`, `*_bom.csv` |
| Посадка + ручные хвосты | pcbnew API, футпринты генерируются кодом (`gen_*`) | `.kicad_pcb` + `.dsn` |
| Автороутер | Freerouting `freerouting-new.jar` DSN→SES + **свой** `import_ses` | дополненная плата |
| Арбитр | `kicad-cli pcb drc --format json` | `drc.json` (цель: нули) |
| Заказ | `kicad-cli pcb export gerbers/drill/pos`, `pcb render` | gerbers/, drill/, рендеры |

## Окружение без sudo

- KiCad 9: .deb распакованы `dpkg-deb -x` в `~/.opt/kicad-root`; подключение —
  `source cad/kicad_env.sh` (PATH, pcbnew, `KICAD_SYMBOL_DIR`/`KICAD_FOOTPRINT_DIR`).
- Freerouting: `~/.opt/kicad-root/freerouting-new.jar` + JDK 25 там же.
- SKiDL: pip в проектный venv; byproducts (`*.erc`, `*_sklib.py`) — в `.gitignore`.
- Сгенерированное (`.kicad_pcb`, `.dsn/.ses`, `drc.json`, gerbers/) — в `_resurses/`,
  не под гитом; под гитом только скрипты.

## Приёмы, которые сработали

- **Ручные хвосты через `wire_checked/via_checked`**: каждый сегмент/виас
  проверяется по факту через `obstacles()` (чужая медь слоя) + микроподбор сдвига
  по нормали ±0.2; при неудаче — громкий `WIRE/VIA BLOCKED` с контекстом
  (цепь, координаты, что мешает), а не молчаливый брак.
- **Порог `seg_ok`**: `w + margin` (у нас 0.075 + 0.1 = 0.175) край-к-краю;
  для падов — точная проверка через углы прямоугольника.
- **B.Cu не видит SMD-пады** (они только на F.Cu) — учитывать в `obstacles()`;
  THT-пады и виасы видны на обоих слоях.
- **Короткие цепи замыкать слиянием меди**: тест-пада внахлёст на пад той же цепи
  (конец *вглубь* пада, не ровно на кромку — DRC касание кромки не видит).
- **Острова одной цепи** (GND): дампить медь из готовой платы через pcbnew
  (треки/виасы/пады по неткоду) и замыкать мостами вручную, не гадать.
- **Отладочный цикл**: `WIRE BLOCKED` → читать фактические координаты из ошибки →
  править геометрией, `DRC NOT CLEAN` → смотреть `drc.json` (тип, цепь, pos).

## Проверка «глазами» (обязательный шаг перед заказом)

1. **Не верить рендеру на 100%.** `kicad-cli pcb render` рисует сверла и
   кольца виасов **вопреки флагу tenting** — на картинке отверстия есть, а на
   Gerber маски их нет. Авторитет — маска: число вспышек `D03` в `*-F_Mask.gts`
   должно равняться числу площадок (у нас 42), в `*-B_Mask.gbs` — числу PTH (3).
   Больше вспышек → есть открытые отверстия виасов.
2. **Ориентацию рендера проверять, а не assume.** Собрать кластеры светлых
   пикселей (открытая маска = площадки) и сопоставить с боксами из файла:
   `--side top` → без зеркала, `--side bottom` → с зеркалом по X. Если «не та
   сторона» — сначала искать баг в своём маппинге (инвертированный флаг), а не
   в плате.
3. **Аудит геометрии скриптом** (быстрее и надёжнее глаза): пары площадок с
   зазором ≤ 0.03 мм; для каждой площадки — расстояние от центра сверла
   (виаса и PTH) до её бокса и сравнить с радиусом сверла. Печатать реф.пин,
   цепь, заход в мм. Всё найденное должно быть SAME NET.
4. Оверлей `PIL`-ом: контуры площадок из `pcbnew` + подписи `U1.20`, цвета по
   цепям, красным — сверла. Класть в `_resurses/` рядом с рендерами.

## Оценка риска находок (что можно оставлять)

- **Виас внутри своей площадки** (GND-в EPAD, виас на краевом контакте) —
  норма для тепловывода и переключения слоя; оставлять.
- **Площадка частично накрывает сверло виаса той же цепи** — оставлять: виас
  притенён, паста туда не попадёт, цепь та же. Косметика рендера, не железа.
- **Слияние двух площадок одной цепи** (тест-пада на пад МК) — норма, если
  площадка тест-пада ≥ 0.5 мм и есть центр под погонь.

## Грабли (все наступлены)

- Штатный `pcbnew.ImportSpecctraSES` возвращает `False` молча — писать свой парсер SES.
- Freerouting v2.1.0 не знает флаг `copperToEdgeClearanceUm`
  (`NoSuchFieldException`); v2.4.1 принимает. Дефолт роутера 500 мкм от края.
- DSN несёт дефолты ширины/зазора 0.2/0.2 — править в тексте на правила ТЗ;
  инверсия Y DSN→плата учитывается при импорте.
- `SaveBoard` перезатирает `.kicad_pro` — патч неткласса делать ПОСЛЕ сохранения.
- Неиспользуемые пины МК оставлять БЕЗ цепи, иначе DRC требует их разводить.
- Шёлк стоковых футпринтов сыплет DRC — чистить (`strip_silk`); дворы умышленно
  пересекающихся деталей — тоже, с фиксацией исключения кодом.
- Дубли треков (роутер поверх ручных) безвредны, если та же цепь.
