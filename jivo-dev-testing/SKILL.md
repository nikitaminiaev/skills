# Jivo Dev Testing — tmux-механика удаленного тестирования

Полное тестирование выполняется на удаленном dev-сервере через tmux-сессию.
Этот скилл — общий способ работы с tmux; команды и пути конкретного проекта
смотри в проектном скилле `api-dev`.

## Посылай команды к серверу этим способом:

```bash
tmux send-keys -t {name}
```

Потом захват вывода например так:
```bash
sleep 1 && tmux capture-pane -t {name}:0 -p | tail -20
```

## Если команда слишком длинная:

Передавай через PHP base64 decode на сервере:
```bash
b64=$(cat /tmp/opencode/file.b64)
tmux send-keys -t dev "php -r 'file_put_contents(\"path/to/target/file.php\", base64_decode(\"$b64\"));'"
```

Или записывай во временный файл на сервере через heredoc, потом раскодируй.

## Общий принцип

Код на dev-сервере лежит в release-директориях проекта, локальные изменения
**не отражаются** на сервере — все правки нужно делать через tmux на сервере.
Конкретные пути и команды (проверка синтаксиса, кеш, php-fpm, тесты, debug-логи)
— в проектном скилле `api-dev`.
